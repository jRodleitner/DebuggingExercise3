### Why the Temporary Files Are Never Deleted

Your code currently leaves temporary files behind for two distinct reasons:

1. **Exceptions bypass the delete command:** If `tester.compileAndExtractError()` throws an exception (which is common when intentionally breaking files), execution immediately jumps out of the loop. The line `Files.delete(tempFile);` is never reached, leaving the `.tex` file on your disk.
2. **LaTeX generates auxiliary files:** When `pdflatex` compiles `ddmin123.tex`, it doesn't just read the file; it generates sidecar files like `ddmin123.log`, `ddmin123.aux`, and potentially `ddmin123.pdf` or `ddmin123.out`. Your code only tells Java to delete the `.tex` file. The compiler artifacts are completely ignored and abandoned in your temporary folder.

---

### The Solution: A Clean-Up Block

To fix this, you must wrap the compilation in a `try-finally` block to guarantee execution, and manually target the auxiliary files LaTeX creates.

Replace these specific lines in your current code:

```java
            // Write temporary test file
            Path tempFile =
                    Files.createTempFile("ddmin", ".tex");

            Files.write(tempFile, candidate);

            // Compile candidate
            Error error =
                    tester.compileAndExtractError(
                            tempFile.toString()
                    );

            // Delete temporary file
            Files.delete(tempFile);

```

**With this new block:**

```java
            Path tempFile = Files.createTempFile("ddmin", ".tex");
            Files.write(tempFile, candidate);

            Error error = null;
            try {
                error = tester.compileAndExtractError(tempFile.toString());
            } finally {
                String basePath = tempFile.toString().substring(0, tempFile.toString().lastIndexOf('.'));

                Files.deleteIfExists(tempFile);
                Files.deleteIfExists(Paths.get(basePath + ".log"));
                Files.deleteIfExists(Paths.get(basePath + ".aux"));
                Files.deleteIfExists(Paths.get(basePath + ".pdf"));
                Files.deleteIfExists(Paths.get(basePath + ".out"));
            }

```

---

### Line-by-Line Breakdown: How and Why it Works

**`Error error = null;`**

* **Where it belongs:** Right before the `try` block.
* **Why it works:** Because variables declared inside a `try` block fall out of scope once the block ends. We must declare `error` outside so the later check (`if (targetError.equals(error))`) can still read it.

**`try { error = tester.compileAndExtractError(tempFile.toString()); }`**

* **Where it belongs:** Wrapping the compilation step.
* **Why it works:** This tells Java to attempt the compilation. If an exception occurs during parsing or running the external process, Java catches the failure but guarantees it will move immediately to the `finally` block before crashing or throwing the error up the chain.

**`finally {`**

* **Where it belongs:** Immediately after the `try` block.
* **Why it works:** Code inside a `finally` block executes 100% of the time, regardless of whether the code inside the `try` block succeeded, failed, or threw a fatal exception. This guarantees your cleanup runs.

**`String basePath = tempFile.toString().substring(0, tempFile.toString().lastIndexOf('.'));`**

* **Where it belongs:** The first line inside the `finally` block.
* **Why it works:** If your temp file is `/tmp/ddmin12345.tex`, this line finds the last `.` and slices the string to isolate `/tmp/ddmin12345`. This gives us the exact prefix LaTeX uses to name all its generated files.

**`Files.deleteIfExists(tempFile);`**

* **Where it belongs:** Inside the `finally` block.
* **Why it works:** We switch from `Files.delete()` to `Files.deleteIfExists()`. If something caused the file creation to fail earlier, `delete()` would throw a new exception and crash the cleanup process. `deleteIfExists()` safely ignores missing files.

**`Files.deleteIfExists(Paths.get(basePath + ".log"));`** (and `.aux`, `.pdf`, `.out`)

* **Where it belongs:** After deleting the main `.tex` file.
* **Why it works:** This appends the LaTeX artifact extensions to our `basePath` (e.g., creating `/tmp/ddmin12345.log`) and deletes them. Using `deleteIfExists()` is crucial here, because a severely broken `.tex` file might crash the compiler before it generates a `.pdf` or `.aux` file.
